# Q&A

## How is Lineform different from Mermaid?

Lineform supports table-like lane diagrams with arrows. For example, a lane table can connect to a conclusion box below it. Its flow diagrams use straight line segments with right-angle bends rather than curved connectors.

The focus is on the visual result I wanted: aligned tables and boxes, connected by arrows without curves.

## Isn't Mermaid more convenient?

Yes. In a Markdown environment that already supports Mermaid, it is more convenient to use. Lineform currently requires adding its JavaScript renderer to your web page or Markdown viewer.

I use Mermaid regularly and like it. But I didn't like how its curved arrows were being routed in my diagrams, so I built a separate tool to get the output I wanted. Lineform reflects that preference; it is not intended to replace everything Mermaid does.
